Say it once. It stays said.

Three things, kept apart

What's true, how you work, who it helps.

Most agent chats forget everything between sessions. Prompt dumps and hand-edited YAML try to fix that, and become someone's maintenance burden. AgentRoot stores each concern in its own place, as flat files you can read.

What's true about this project

Memory

Short one-sentence facts. What you say is active at once; you can withdraw any of them.

How we usually do this kind of work

Skills

Procedures, kept only after you confirm them. A scored run that does worse sends one back.

Who the assistant is helping

Role

Identity and lens, not a step-by-step manual. General by default.

Confirm before keep

Guesswork waits for your yes.

Nothing becomes a kept procedure without your confirmation. The assistant offers what is waiting, at most three at a time, at the start and end of a run.

  1. DiscoverRole, Knowledge, the Memory hot set, the tools connected now
  2. ExecuteA matching confirmed Skill, else a builtin
  3. RememberWhat you said goes active; what it inferred stays proposed
  4. Confirmmemory review is the gate; nothing activates itself
  5. ReuseNext time, Memory and the Skill load; tools re-bind to what is connected
How capability stacks

Climb when you need to. Nothing breaks if you don't.

Each level sits on the one below. A missing level weakens only itself — no MCP and no Score still leave builtins and Memory useful.

  1. T5
    Trace + ScoreScore each run against a signed Answer key
  2. T4
    MCP toolsOptional live tools, re-discovered each run
  3. T3
    Confirmed SkillsRepeatable procedures you explicitly approved
  4. T2
    MemoryProject facts persist across sessions
  5. T1
    Builtins + work/Research, Analyze, Brainstorm, Report out of the box
Quick start

Two commands, then open the folder.

Requires Python 3.11+. Install the agentzero command once — no clone needed.

# install once (pipx install works the same)
uv tool install git+https://github.com/jesselei1102-hue/agentzero

# make a workspace for your tool: cursor | codex | claude
agentzero init ~/AgentZero-Workspace --harness claude
  1. Give tasks in plain language.No new commands to learn for day-to-day work.
  2. State facts as you go."We use millimetres." Say "forget that" to withdraw one.
  3. Answer what's waiting../a0 memory review lists it as sentences.
  4. Hand over references.Standards and templates become Knowledge later chats can use.
Design principles

Conventions, not a new runtime.

01

Convention over runtime

Adapts onto the harness you have. The agent loop stays in Cursor, Codex or Claude Code.

02

Confirm before keep

Proposed until you say yes. Reuse must not quietly degrade.

03

Operator-visible files

Flat YAML and Markdown you can audit. No hidden control plane.

04

Domain-agnostic core

The first proof is not the product boundary.

05

Tiers degrade independently

Skip a level and only that level is gone.

Not a new agent runtime. The LLM loop stays where it is.
Not an SDK-first product. Files and chat are the surface; src/ is there if you want to dig.
